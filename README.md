# Digital Nurture 5.0 - Java FSE

This repository contains exercise solutions for the Cognizant Java FSE Upskilling program.

## Core Java (41 Exercises)

1. **HelloWorld** - basic program structure and console output
2. **SimpleCalculator** - arithmetic operations with user input
3. **EvenOdd** - even/odd check using modulus operator
4. **LeapYear** - leap year check with nested conditional logic
5. **MultiplicationTable** - for loop from 1 to 10
6. **DataTypesDemo** - int, float, double, char, boolean variables
7. **TypeCastingExample** - double to int and int to double casting
8. **OperatorPrecedence** - expression evaluation with multiple operators
9. **GradeCalculator** - if-else grade assignment (A/B/C/D/F)
10. **NumberGuessingGame** - random number guessing with high/low feedback
11. **FactorialCalculator** - factorial using a for loop
12. **MethodOverloadingDemo** - overloaded add methods (int, double, three ints)
13. **RecursiveFibonacci** - nth Fibonacci number using recursion
14. **ArraySumAverage** - sum and average of array elements
15. **StringReversal** - reverse string using StringBuilder
16. **PalindromeChecker** - palindrome check with alphanumeric cleaning
17. **CarDemo** - class with attributes (make, model, year) and displayDetails()
18. **InheritanceExample** - Animal base class and Dog subclass with override
19. **InterfaceDemo** - Playable interface with Guitar and Piano implementations
20. **TryCatchExample** - division by zero with ArithmeticException handling
21. **Custom Exception** - InvalidAgeException thrown for age under 18
22. **FileWriterExample** - write user input to output.txt
23. **FileReaderExample** - read and display output.txt
24. **ArrayListExample** - store and display student names
25. **HashMapExample** - map student IDs to names with search
26. **ThreadCreation** - two threads extending Thread with messages
27. **LambdaSort** - sort strings using Collections.sort with lambda
28. **StreamFilterEven** - filter even numbers using Stream API
29. **PersonRecordDemo** - Java record with stream filtering by age
30. **PatternSwitchDemo** - pattern matching switch on Integer, String, Double
31. **BasicJDBCConnection** - JDBC driver, SQLite connection, create table, SELECT
32. **JDBCInsertUpdate** - StudentDAO with PreparedStatement insert and update
33. **JDBCTransactionDemo** - account transfer with commit and rollback
34. **Java Modules** - com.greetings and com.utils modules with module-info
35. **ChatServer and ChatClient** - TCP socket two-way communication
36. **HttpClientExample** - HTTP GET request using Java HttpClient
37. **JavapDemo** - sample class for javap bytecode inspection
38. **DecompileDemo** - sample class for JD-GUI or CFR decompiler
39. **ReflectionDemo** - forName, getDeclaredMethods, and invoke
40. **VirtualThreadsDemo** - 100,000 virtual threads with timing comparison
41. **ExecutorCallableDemo** - ExecutorService, Callable, and Future
