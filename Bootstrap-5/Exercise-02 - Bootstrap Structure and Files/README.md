# Exercise 02 - Bootstrap Structure and Files

This exercise explains the Bootstrap folder structure and shows how to include the JS bundle.

Files:
- 02-1-structure.html - short explanation of the CSS, JS, and icons folders
- 02-2-bundle.html - example including `bootstrap.bundle.min.js`

Concepts: distribution layout, purpose of CSS/JS/icons, and bundle vs separate Popper plus plugins.
