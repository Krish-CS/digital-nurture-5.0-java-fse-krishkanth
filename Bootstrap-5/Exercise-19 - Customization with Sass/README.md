# Exercise 19 - Customization with Sass

This exercise shows how to set up Bootstrap 5 with Sass using npm and how to customize the theme.

Files:
- package.json - npm configuration with the build script and dependencies
- custom.scss - source file overriding the primary color and border radius before importing Bootstrap
- 19-1-sass.html - page showing the Sass setup and build script
- 19-2-customize.html - page using the compiled `custom.css` with the custom purple button and rounded corners

Concepts: npm setup, Sass variables, recompiling Bootstrap, and simple theme changes.
