# Exercise 18 - Bootstrap 5 JavaScript Plugins

Demonstrates core dynamic interactive behaviors controlled via Bootstrap's built-in JavaScript.

Files:
- 18-1-modal.html — triggers a sliding alert window modal dialog (`.modal fade`) upon clicking a target button via data attributes (`data-bs-toggle="modal"`)
- 18-2-accordion.html — collapsible information panel (`.accordion`) grouping nested blocks under headers that toggle display visibility smoothly
