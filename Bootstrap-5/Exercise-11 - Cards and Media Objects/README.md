# Exercise 11 - Cards and Media Objects

Demonstrates profile card components and dynamic content alignment mimicking media objects.

Files:
- 11-1-card.html — a clean profile badge card displaying an avatar image, titles, subtitle overlays, descriptive text block, and registration buttons
- 11-2-media.html — reproduces deprecated media layouts utilizing standard Bootstrap 5 flexbox classes (`d-flex`, `flex-shrink-0`, and `flex-grow-1`) to align an avatar alongside textual commentary blocks
