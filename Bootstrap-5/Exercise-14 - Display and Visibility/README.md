# Exercise 14 - Display and Visibility

Demonstrates responsive display behavior toggles across different breakpoints.

Files:
- 14-1-display.html — responsive block rendering using combinations like `d-none d-md-block` and `d-block d-lg-flex` to layout content based on screen size
- 14-2-sidebar.html — standard responsive side navigation layout that automatically hides on mobile screens (`d-none`) and pops in on tablets and larger (`d-md-block`)
