# Exercise 07 - Typography

Demonstrates basic typography scale, helpers, and text capitalization modifiers.

Files:
- 07-1-typo.html — shows headings, display scale (`display-1`, `display-4`), `lead` paragraph text, weight helpers (`fw-bold`, `fw-light`), styles (`fst-italic`), and custom font-sizes (`fs-3`)
- 07-2-cases.html — illustrates text transformations (`text-uppercase`, `text-lowercase`, and `text-capitalize`)
