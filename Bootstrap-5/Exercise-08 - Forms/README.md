# Exercise 08 - Forms

Demonstrates core Bootstrap 5 form styles, floating labels, input prefixes, selection, and checkbox layout styles.

Files:
- 08-1-register.html — event registration form showing use of `.form-control`, `.form-select`, `.form-check`, and `.input-group` (prefixed inputs)
- 08-2-floating.html — portal sign-in form using floating labels `.form-floating` for input fields
