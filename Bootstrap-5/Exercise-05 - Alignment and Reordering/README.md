# Exercise 05 - Alignment and Reordering

Demonstrates row centering, vertical alignment, and responsive grid column order swap.

Files:
- 05-1-align.html — centers a column inside a row using `justify-content-center` and `align-items-center`
- 05-2-order.html — reorders columns responsively using `order-md-2` and `order-md-1`
