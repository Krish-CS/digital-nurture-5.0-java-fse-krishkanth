# Exercise 16 - Positioning Utilities

Demonstrates fixed, absolute, and relative positioning utility patterns.

Files:
- 16-1-fixed.html — a sticky website footer locked at the base of the viewport using `.position-fixed bottom-0`
- 16-2-absolute.html — custom notification counter badge overlay layered precisely over the corner of a profile avatar using `.position-relative`, `.position-absolute`, and `.translate-middle`
