# Exercise 03 - Responsive Grid Layout

This exercise demonstrates a responsive grid with three columns that stack on mobile, show two per row on tablets, and three per row on desktops.

Files:
- 03-1-grid.html - the basic responsive three-column grid
- 03-2-grid.html - a short example showing the same grid classes in a simple layout

Concepts: container, row, col classes, and responsive stacking behavior.
