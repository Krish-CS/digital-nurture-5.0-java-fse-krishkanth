# Exercise 06 - Responsive Flexbox Utilities

Demonstrates basic responsive flexbox utilities for structural blocks.

Files:
- 06-1-navbar.html — a simple navbar that transitions from a vertical column to a horizontal row on tablets and larger using `flex-column` and `flex-md-row`
- 06-2-card.html — aligns an event title, seat indicator, and action button cleanly inside a card using `justify-content-between` and `align-items-center`
