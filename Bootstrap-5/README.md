# Bootstrap 5

This folder contains the Bootstrap 5 module exercises for the Cognizant Java FSE Upskilling program.

## Folder Layout

- `Exercise-01` to `Exercise-18` contain the Bootstrap practice pages
- `Exercise-19 - Customization with Sass` contains the Sass setup and compiled custom theme
- `icons/` stores a small local note for the Bootstrap Icons structure exercise
- `node_modules/` contains the installed Bootstrap and Bootstrap Icons packages used by local examples
