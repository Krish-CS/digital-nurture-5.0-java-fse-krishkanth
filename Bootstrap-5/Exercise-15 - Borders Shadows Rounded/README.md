# Exercise 15 - Borders, Shadows, and Rounded Corners

Demonstrates border colors, card shadows, and rounded corners on images and button elements.

Files:
- 15-1-borders.html — circular user profile image styled using `.border`, `.border-primary`, `.border-3`, and `.rounded-circle`
- 15-2-shadows.html — card components illustrating slight shadows `.shadow-sm` vs prominent shadows `.shadow-lg` combined with capsule-shaped buttons `.rounded-pill`
