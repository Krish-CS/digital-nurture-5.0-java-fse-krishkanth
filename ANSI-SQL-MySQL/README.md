# ANSI SQL Using MySQL Exercises

This folder contains SQL exercises for an Event Management System.

## Database Schema

The database consists of the following tables:
1. **Users**: User profiles and registration info.
2. **Events**: Details of tech meetups, conferences, etc.
3. **Sessions**: Specific sessions within an event.
4. **Registrations**: Mapping of users to events they attend.
5. **Feedback**: Ratings and comments from users after events.
6. **Resources**: Links, PDFs, and images associated with events.

To set up the database and populate it with sample data, run:
