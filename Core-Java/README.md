# Core Java

This folder contains solutions for the Core Java module of the Cognizant Java FSE Upskilling program.

## Exercises 1-10

- `HelloWorld` - basic Java program structure and console output
- `SimpleCalculator` - arithmetic operations with user input
- `EvenOdd` - even or odd check using the modulus operator
- `LeapYear` - leap year check using conditional logic
- `MultiplicationTable` - multiplication table using a `for` loop
- `DataTypesDemo` - primitive data type values
- `TypeCastingExample` - casting between `double` and `int`
- `OperatorPrecedence` - expression evaluation order
- `GradeCalculator` - grade assignment using `if-else`
- `NumberGuessingGame` - random number guessing with loop feedback

## Exercises 11-20

- `FactorialCalculator` - factorial using a loop
- `MethodOverloadingDemo` - overloaded `add` methods
- `RecursiveFibonacci` - nth Fibonacci number using recursion
- `ArraySumAverage` - sum and average of array values
- `StringReversal` - reverse a user-entered string
- `PalindromeChecker` - palindrome check after cleaning input
- `CarDemo` - class, object, attributes, and `displayDetails()`
- `InheritanceExample` - `Animal` and `Dog` inheritance example
- `InterfaceDemo` - `Playable` interface with `Guitar` and `Piano`
- `TryCatchExample` - division by zero handling with `try-catch`

## Exercises 21-30

- `Exercise21` and `InvalidAgeException` - custom exception for invalid age
- `FileWriterExample` - write user input to `output.txt`
- `FileReaderExample` - read and display `output.txt`
- `ArrayListExample` - store and display student names
- `HashMapExample` - map student IDs to names
- `ThreadCreation` - create and run two threads
- `LambdaSort` - sort strings using a lambda expression
- `StreamFilterEven` - filter even numbers using streams
- `PersonRecordDemo` - record type and stream filtering
- `PatternSwitchDemo` - pattern matching with switch expression

## Exercises 31-41

- `BasicJDBCConnection` - load JDBC driver, connect to SQLite, create table, and select students
- `JDBCInsertUpdate` - `StudentDAO` with insert and update using `PreparedStatement`
- `JDBCTransactionDemo` - transaction handling with commit and rollback
- `Java Modules` - `com.greetings` and `com.utils` modules
- `ChatServer` and `ChatClient` - simple TCP client-server chat
- `HttpClientExample` - HTTP request using Java HTTP Client
- `JavapDemo` - sample class for `javap -c` bytecode inspection
- `DecompileDemo` - sample class for decompiler tools such as JD-GUI or CFR
- `ReflectionDemo` - method listing, parameter types, and dynamic invocation
- `VirtualThreadsDemo` - 100,000 virtual threads with a simple timing comparison
- `ExecutorCallableDemo` - `ExecutorService`, `Callable`, and `Future`
