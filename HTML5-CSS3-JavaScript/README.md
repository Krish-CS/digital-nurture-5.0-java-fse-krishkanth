# HTML5, CSS3, and JavaScript

This folder contains the Local Community Event Portal project for the HTML5, CSS3, and JavaScript module.

## Module 1 - Web Stack

- **Project**: Local Community Event Portal (HTML/CSS/JS)
- **Concepts**: semantic HTML, external CSS, responsive layout, DOM manipulation, events, closures, prototypes, promises/fetch, geolocation
- **Features**: dynamic event rendering, filtering, registration form, loading spinner, mock JSON fetch
- **Events**: Community Cleanup Drive, Tree Plantation, Food Festival, Tech Meetup, Marathon, Cultural Event
